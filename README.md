# PockIt

App personal pa' jugar GTA VI con **Marisol Madrigal** de copiloto. Abre el Project "GTA VI" de claude.ai dentro de Pockit y le agrega tracker, avatar animado, botones rápidos y más.

- `ios/` — app de iPhone/iPad (SwiftUI). GitHub Actions compila la IPA en cada push a `main` y la publica en **Releases** como `Pockit_<versión>(<build>).ipa`. Se instala con Signulous.
- `assets/` — arte original: íconos, póster de Marisol, sus 8 caras y los clips de transición (MP4 HEVC).

Spec completo: en el Project "GTA VI" de claude.ai (`pockit-spec.md`).

Fuente Anton: SIL Open Font License 1.1 (`ios/Pockit/Resources/Fonts/Anton-OFL.txt`).
